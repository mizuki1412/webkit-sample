# Aurora Design Language · v1.0

> 从 `pics/30b0f259164b06e182a77f475edc3c34.webp`（PROJEX 项目管理看板）反演的可执行设计语言。
> 一句话：**浅蓝灰画布上的白卡片，皇家蓝是唯一行动色，粉彩只做分类，大圆角撑起亲和感。**
>
> - 机器可读：`tokens.json`（DTCG）→ `build/theme.css` / `build/tailwind.v4.css` / `build/tokens.js`
> - 证据：`measurements.json`（像素实测）+ `semantic-map.json`（角色映射）
> - 与其他语言的关系：与 Noir（暗·金融）、Porcelain（浅·商务）共享同一 **token 语义契约**（同名变量），但值域互不兼容，不可混用。

## 1. 设计主张

| # | 原则 | 落地 |
|---|------|------|
| 1 | 皇家蓝是唯一的行动色 | 主按钮、选中态、导航激活、链接；实测占比 20.4%（大色块）但语义单一 |
| 2 | 白卡片浮在浅蓝灰画布上 | 卡片不加边框依赖，用画布/表面明度差 + 柔和阴影 |
| 3 | 粉彩是分类语义，不是装饰 | 日历事件、标签、状态点用粉彩（weak 色）；对应深色用于其文字 |
| 4 | 圆角是身份 | 卡片 20 / 控件 14 / 胶囊 full；禁止出现 ≤6px 直角感控件 |
| 5 | 胶囊贯穿控件层 | 搜索框、分段控件、日期标签、按钮（主按钮可用 10px） |

## 2. 使用规则（给 Agent）

1. 只用 `build/theme.css` 的 CSS 变量；不写裸 hex、不写魔法 px。
2. 主行动区面积可大（侧栏整条、选中卡片整卡变蓝）——这是与其他两套语言最大的差异。
3. 文字颜色永远成对：`text` + `text-muted` + `text-faint`；蓝底上一律 `accent-ink`（白）。
4. 数据可视化：主数据线 `data-1`(=accent)，次线紫/粉；网格线 `chart-grid`。
5. 阴影允许且柔和：只用 `shadow.card` token（`--shadow-card`）一档，禁多层深影。
6. 提交前跑 `python tools/design_lint.py <files>`。

## 3. 组件形态（样图明确出现）

- **侧栏**：整条 accent 底，未选中项白 84% 文字；选中项 = 白胶囊 + 蓝字 + 侧边 notch 缺口。
- **顶栏**：无独立底色，与画布同色；搜索框为白胶囊（h40，radius full）。
- **卡片**：radius-lg(20)，白底，card-pad 24；可带 3px 彩色左边条（分类色）。
- **选中卡片**：整卡 accent 底、白字、稍放大（样图第二卡）。
- **分段控件**：胶囊组，选中项 accent 底白字（Month/Day/Week/Today）。
- **日历事件块**：粉彩底 + 分类深色字，radius-sm，左侧 3px 深色竖条。

## 4. 测得 vs 推断

- **测得**（measurements.json）：#005EFD / #FFFFFF / #F0F3FA / #F5F8FC 及粉彩族；4px 间距网格；布局包围盒。
- **推断**（样图为静态、无字体信息）：交互态（hover/焦点）、字重节奏、字阶精确值（±1px）、阴影强度、动效时长。
- 圆角 20/14/10 由边缘检测 13.5–15.5px 区间按 1600px 预览宽归一，置信度中。
